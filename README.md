# Minesweeper C++ (OOP)

## Cấu trúc
- `include/` — Header files
- `src/` — Source files
- `Makefile` — Build script

## Kiến trúc
- **Cell**: 1 ô vuông
- **Board**: Bàn cờ, logic game
- **Game**: Vòng lặp, giao diện

## Biên dịch
    make
    ./minesweeper

## Cách chơi
- `r c` — mở ô (hàng, cột)
- `f r c` — cắm/bỏ cờ
- `c r c` — chord (mở nhanh)
- `q` — thoát
